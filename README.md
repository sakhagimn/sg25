# Саха гимназия — 25 лет

Распакуйте архив и откройте index.html. Установка не требуется. Сайт не опубликован.

## Структура
- index.html — главная с 14 карточками.
- events/01.html … 14.html — страницы мероприятий.
- assets/style.css — оформление.
- assets/media.js — список фото и видео.
- media/01 … 14 — папки материалов.

## Добавить фото и видео
Скопируйте файлы в папку соответствующего мероприятия. В assets/media.js замените, например, "01": [] на:

```js
"01": [
  {type: "photo", src: "media/01/photo1.jpg", alt: "Фото мероприятия"},
  {type: "video", src: "media/01/video1.mp4"}
]
```

Материалы идут сверху вниз в указанном порядке. Поле alt — описание фото для доступности, а не видимая подпись. Заголовков, подписей, текстовых блоков и сообщений о пустом разделе нет. Фото открывается крупно по нажатию. Видео воспроизводится встроенным плеером.

Используйте JPG, PNG, WebP для фото; MP4 с H.264/AAC для видео. Между записями и мероприятиями оставляйте запятые. После сохранения обновите страницу. Для размещённого сайта загрузите новые файлы и обновлённый media.js на хостинг. Прямая https-ссылка на медиафайл также поддерживается; ссылка на страницу видеосервиса не заменяет видеофайл.

## Тексты
HTML-файлы имеют переносы строк и отступы. Содержание страниц соответствует предоставленным источникам. Для изменения названия на главной и странице мероприятия редактируйте оба HTML-файла.
